## Instalação local

1. Usar PostgreSQL 16, Python 3.12 e a versão Node de `frontend/.nvmrc`.
2. Copiar `.env.example` para configuração local privada; seguir
   `docs/13-guia-execucao-ambientes.md`. Não reutilizar segredos de teste.
3. Instalar backend com `pip install --require-hashes -r requirements-dev.lock.txt`
   na pasta backend; frontend com `npm ci` na pasta frontend.
4. Executar `alembic upgrade head`, conferir `alembic current` e `alembic check`.
   Head esperado: `20261023_0035`, único. Não usar stamp como substituto.
5. Executar a aplicação conforme o guia; validar `/ready`, autenticação e RBAC.
6. Para fila local, usar o processo separado
   `python -m app.modules.notifications.worker`, conforme README de notifications.
   WhatsApp permanece simulado. Anexos usam diretório privado local configurado;
   não apresentar esse adapter como storage de produção.

## Compatibilidade e limites

- 200 volumes físicos totais por otimização síncrona, inclusive multi-caminhão.
- Preservadas idempotência, invariantes físicas, snapshots, rastreabilidade,
  MFA, CSRF e permissões efetivas.
- Sem multiempresa, CoreFlow ou requisitos da v1.3.0.
- Hospedagem, domínios, segredos e deploy externo não integram este aceite de código.

## Backup e rollback

Antes de atualizar qualquer ambiente, parar escritores e worker e criar backup
coerente do PostgreSQL e dos objetos privados. Guardar revisão, imagem, configuração
e inventário de arquivos sem expor segredos. Restaurar primeiro em banco e diretório
separados; verificar head, contagens, chaves e leitura autorizada de anexos.

`CONFIRMADO`: migrations podem recusar downgrade com dados existentes, inclusive
identidades idempotentes da revisão 0035. Não apagar registros para forçar downgrade.
Rollback seguro de versão exige retorno ao snapshot completo anterior em ambiente
separado e reconciliação explícita das escritas posteriores; pode implicar janela
de indisponibilidade. Não apontar binário antigo para schema novo sem compatibilidade
testada. O ensaio local não certifica backups de ambientes externos.
