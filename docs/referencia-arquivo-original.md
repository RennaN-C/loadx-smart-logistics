# Referência do ZIP original

A estrutura recebida descrevia uma plataforma logística ampla com paletes, rotas, GPS, câmera, previsões, MDF-e e aprendizado contínuo.

Esta base preservou as ideias úteis, mas retirou do MVP:

- paletes;
- GPS/geolocalização real;
- câmera/OpenCV;
- manifestos fiscais;
- previsões e riscos avançados;
- aprendizado contínuo;
- painéis separados de cliente e TI;
- arquitetura preparada para recursos ainda não contratados.

Esses itens podem ser reavaliados após o fluxo principal funcionar de ponta a ponta.
