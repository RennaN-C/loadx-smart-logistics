LOADX - DECISÕES NECESSÁRIAS DA EQUIPE PARA O BACKEND
======================================================

Objetivo
--------
Este arquivo é uma pauta de decisão. Ele não substitui docs/11-riscos-pendencias.md nem uma ADR.

CONFIRMADO: uma escolha só passa a valer depois de registrada no documento oficial correspondente, revisada pela equipe e vinculada a uma ocorrência.

Como usar
---------
1. Discutir cada item DXX.
2. Registrar a opção escolhida, responsáveis e data.
3. Atualizar docs/03, docs/04, docs/05 ou docs/11 conforme o assunto.
4. Criar ADR quando a decisão alterar arquitetura, segurança, contrato permanente ou padrão transacional.
5. Somente então desbloquear a ocorrência indicada.
