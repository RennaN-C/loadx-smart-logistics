# Instruções de IA para o frontend

Além do `AGENTS.md` da raiz:

- use React com TypeScript estrito;
- organize código por feature;
- não duplique tipos de API manualmente sem motivo;
- trate loading, vazio e erro;
- não implemente validação geométrica crítica no navegador;
- a cena 3D deve usar as coordenadas retornadas pela API;
- mantenha componentes acessíveis e formulários validados;
- testes não devem depender do backend real.
- siga os padrões de nomes, features, endpoints, erros e testes em `docs/08-padroes-desenvolvimento.md`;
- consulte `docs/09-guia-para-ia.md` antes de criar arquivos novos.
